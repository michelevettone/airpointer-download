# PhonePointer — Support

## Getting started
1. Download the Mac app from the releases page and move **PhonePointer.app** into Applications.
2. Open it and allow **Bluetooth** and **Accessibility** when asked.
3. Open PhonePointer on the iPhone and tap **Pair** next to your Mac.

The Mac app lives in the menu bar (cursor icon). The notch island shows the same controls.

## FAQ

**The cursor doesn't move.**
Accessibility permission is missing: System Settings › Privacy & Security › Accessibility › enable
PhonePointer. Then reopen the app.

**Mission Control / spaces do nothing.**
They are posted through System Events. The first time, macOS asks "PhonePointer wants to control
System Events": allow it. If you denied it, re-enable it in System Settings › Privacy & Security ›
Automation.

**The app pauses by itself.**
It pauses when you use the Mac's own mouse or trackpad, and when the iPhone app goes to the background.
Press Pause/Resume on the phone, in the menu bar, or in the island.

**The phone must stay on.**
iOS suspends motion updates in the background, so keep the app open with the screen on while you use it.
